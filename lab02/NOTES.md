Рабочая папка — это папка на компьютере, где хранятся и редактируются файлы.
Индекс — это промежуточная очередь, куда попадают файлы перед сохранением.
Коммит — это готовое сохранение, которое записывается в историю.

Git — это программа, которая следит за историей версий.
GitHub — это сайт, где эти версии хранятся в облаке.


git status — показывает текущее состояние репозитория.
git diff — показывает разницу между рабочей папкой и последним коммитом.
git diff --staged — показывает разницу между индексом и последним коммитом.


## Ветки
- Ветка — это независимая линия разработки (ответвление истории проекта).
- При новом коммите в текущей ветке указатель этой ветки смещается на новый коммит, а другие ветки остаются на месте.
- Слияние (merge) объединяет изменения из одной ветки в другую, создавая общую историю.
